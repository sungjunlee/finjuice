# 정본 월 마감

`ssot close run`은 해당 월의 데이터 revision, rules/config identity, `cash.v1` 계산 정책, 선언한 source-as-of와 원본 계산 입력을 불변 close revision으로 보존한다. source-as-of는 호출자가 확인한 자료 기준이며 과거 데이터 필터를 가장하지 않는다. 실제 입력 범위는 당시의 고정된 데이터 revision이다.

금액은 원본 계수·소수 자릿수에서 정밀 십진으로 읽고 통화별로 합산한다. 확정된 내부 이체는 수입·지출 순액에서 제외한다. 미지 통화·검토 대기·이체 미결정·월 경계 시간대·미대사/부분대사 증빙은 미해결 상태에 포함한다.

`--asset-scope transactions_and_asset_snapshots`를 지정하면 `--party-id`와 `--valuation-currency`를 명시해야 한다. 선택적으로 반복 `--source-id`로 자료 범위를 고정한다. 자산 값은 원본 스냅샷의 단순 합계가 아니라 기존 확정 의미·소유 지분·부분/과거 자료·포함 관계·부호/FX 정책을 적용한 동일한 정본 보고 결과다. 미확인 사항은 마감에도 보존한다.

닫힌 달은 직접 덮어쓸 수 없다. `ssot close reopen`이 재개방 사실만 추가하며, 다음 run은 이전 close와 연결된 새 revision 및 차이/이유를 남긴다. 이후 거래를 되돌리지 않는다.

`ssot close history`는 현재 거래를 다시 읽어 과거 값을 바꾸지 않는다. 각 close에 고정한 거래 입력·자산 판단 보고·대사 상태에서 보고를 재생성하고 저장된 digest/합계와 대조한다. 큰 금액과 나중 이체 판단, 부분 자산 뒤 의미 정정, 실제 백업/복원 후에도 최초 close는 유지된다.

schema9의 두 불변 테이블은 기존 schema4–8 raw 복원을 변경하지 않으며 명시적 clone upgrade는 빈 마감 테이블만 추가한다. 과거 마감을 추정 생성하지 않는다. 운영 마감과 비공개 실제 사용의 완료는 별도 수용 증거가 필요하다.
